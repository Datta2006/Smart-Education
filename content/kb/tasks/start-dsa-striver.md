# Start DSA (The Striver A2Z Method)

## Objective
Transition from basic syntax to structured problem-solving using the industry-standard roadmap for Indian engineering students.

## Steps
1. Go to takeuforward.org or search for "Striver A2Z DSA Course" on YouTube.
2. Start with "Step 1: Learn the Basics" and "Step 2: Arrays".
3. Create accounts on LeetCode and GeeksforGeeks.
4. Solve 2-3 problems daily. Do not jump to trees or graphs yet. Master arrays, strings, and basic math.
5. Participate in weekly beginner contests on CodeChef or LeetCode to get used to time limits and nervousness.

## Proof
- 30+ "Easy" problems solved on LeetCode/GFG.
- A consistent green contribution graph on your competitive programming profiles.

## Mentor Note
DSA is not about memorizing code; it is about pattern recognition. If you get stuck, struggle for 20 minutes before looking at the solution.
