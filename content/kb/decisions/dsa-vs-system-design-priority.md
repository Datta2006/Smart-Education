# DSA vs System Design — Where to Spend Time

## Short Answer
DSA first, always — it's the gatekeeper round at almost every company. System design matters only after DSA is interview-solid.

## Spend on DSA if:
- You can't yet solve mediums reliably (see the 450 sheet / Grokking patterns).
- Your target companies run 2+ coding rounds (most Indian companies, all FAANG).
- A coding round failure would end the process — because it usually does.

## Spend on System Design if:
- Your DSA is consistent (mediums within 30 minutes) and you have 6+ weeks left.
- Your targets include senior/product roles or FAANG-style interviews that explicitly have a system design round.
- You want the `study-system-design-grokking` course to compound, not confuse.

## Mentor Recommendation
Rule of thumb: **80% DSA, 20% system design**, moving toward 60/40 only in the final 4 weeks before interviews. A mediocre design answer still passes if your code rounds were clean; the reverse is almost never true. Start system design only when a week of mocks shows your coding is stable.
