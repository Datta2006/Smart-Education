# Setup UNIX Dev Environment & Portfolios

## Objective
Stop using pure Windows GUI or online compilers for coding. Set up a professional, UNIX-based local development environment and create your core tech profiles.

## Steps
1. **Hardware Check:** Ensure your laptop has at least 8GB RAM and an SSD.
2. **OS Setup:** If you have a Mac, you are ready. If you have Windows, dual-boot Ubuntu or set up WSL (Windows Subsystem for Linux). Professional development happens in UNIX environments.
3. **IDE:** Install VS Code.
4. **Create Accounts:** Register on GitHub, LinkedIn, LeetCode, GeeksforGeeks, and HackerRank.
5. **Profile Setup:** Add a professional photo to LinkedIn and a clean bio to GitHub.

## Proof
- A screenshot of your terminal running a basic UNIX command (`ls -l` or `pwd`).
- Links to your newly created GitHub and LeetCode profiles.

## Estimated time
8 hours (mostly downloading and installing OS/WSL).

## Mentor note
Getting comfortable with a black terminal screen is the first rite of passage for a computer science student. Do not skip the OS setup.
