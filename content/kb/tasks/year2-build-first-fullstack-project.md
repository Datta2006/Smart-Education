# Build Your First Full-Stack Project

## Objective
Your first real, deployed full-stack project is the single strongest line on your resume at this stage. It proves you can build end-to-end — not just follow a tutorial.

## Steps
1. **Choose a real problem** you or someone near you faces (mess scheduling, hostel complaints, notes-sharing, a club portal). Avoid the overused to-do and weather apps.
2. **Pick one stack and stick to it:** MERN (MongoDB, Express, React, Node), Django+PostgreSQL, or Next.js + PostgreSQL. One stack — do not shop around.
3. **Plan the schema first:** design your database tables before writing any frontend.
4. **Build in layers:** backend API → database → basic frontend → auth → polish.
5. **Deploy it:** Vercel (frontend) + Supabase/Neon (Postgres) for free. A live URL is 10x more impressive than a GitHub repo.
6. **Write a README** with screenshots, a demo link, and the tech stack.

## Proof
- A live, deployed app with a real URL that works on mobile + desktop.
- GitHub repo with clean commit history and a proper README.
- A 3-sentence summary you can say in interviews: *problem → what you built → result*.

## Mentor Note
Recruiters skim ~30 seconds per resume. Your project line should read like: "Built X to solve Y using Z, deployed at [url]". The demo link matters more than the code. And remember — one deep project beats five half-finished tutorials.
