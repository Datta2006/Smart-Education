# Master the 14 Grokking Coding Patterns

## Objective
Learn the pattern-first method from *Grokking the Coding Interview* (saved as `.mhtml` lessons in `02.. Interview-Preparation-Content/4. Grokking the Coding Interview Patterns.../`) so any new problem maps to a known strategy instead of starting from scratch.

## Steps
1. Open the course lessons and cover the 16 patterns one by one: Sliding Window, Two Pointers, Fast & Slow Pointers, Merge Intervals, Cyclic Sort, In-place Reversal, Tree BFS, Tree DFS, Subsets, Modified Binary Search, Bitwise XOR, Top K Elements, Two Heaps, K-way Merge, Topological Sort, 0/1 Knapsack.
2. For each pattern: read the intro lesson, then solve the 3–6 example problems in that folder (filenames include the difficulty, e.g. `46_Merge_Intervals__medium_.mhtml`).
3. Before coding, name the pattern and the template (e.g. "this is a sliding window — expand right, shrink left").
4. Revisit the pattern intro at the end of the week and try one problem cold.

## Proof
- Can explain each pattern's template in one sentence and its time complexity.
- Solved the full example set for ≥ 10 patterns with logs.
- In a fresh problem, you can classify it into a pattern within 2 minutes.

## Mentor Note
Interviewers hire for pattern recognition, not memorization. The same 16 patterns appear again and again — the course is essentially a cheat code for the first 30 seconds of every coding problem.
