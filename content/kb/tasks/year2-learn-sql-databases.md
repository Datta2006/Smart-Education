# Learn SQL & Databases (Non-Negotiable)

## Objective
SQL appears in **almost every** software/data interview round — from easy warm-up queries to complex joins and window functions. Master it in Year 2 so it's never a surprise later.

## Steps
1. **Learn the basics** with [W3Schools SQL](https://www.w3schools.com/sql/) — SELECT, WHERE, JOINs, GROUP BY, HAVING, subqueries.
2. **Practice daily** on a real database (MySQL/PostgreSQL/online). Use [Oracle Dev Gym](https://devgym.oracle.com/pls/apex/f?p=10001:20011::::20011::) or [SQLZoo](https://sqlzoo.net/).
3. **Level up to window functions and CTEs** — they appear in real interviews. See [GFG SQL query interview questions](https://www.geeksforgeeks.org/sql-query-interview-questions/).
4. **Build a small project:** a database-backed app (library, e-commerce cart) with normalized schema. Prove you can design tables, not just query them.
5. **Practice interview-style questions** from [GFG SQL interview questions](https://www.geeksforgeeks.org/sql-interview-questions/).

## Proof
- 30+ SQL problems solved across join/aggregate/window categories.
- A working database schema + queries for a small project.
- Can explain normalization (1NF–BCNF) and ACID without notes.

## Mentor Note
DBMS theory and SQL practice are two halves of the same coin. Interviewers love asking "design a schema for X" — if you've built one yourself, those questions become easy. Don't leave SQL for Year 3 cramming.
