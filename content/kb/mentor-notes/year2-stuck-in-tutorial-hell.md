# Stuck in Tutorial Hell — The Exit

## Trigger condition
The student has watched many tutorials/courses but has few finished projects, and keeps starting new courses instead of building.

## Mentor message
You're not lazy — you're in the comfort zone. Watching a tutorial feels productive but teaches almost nothing because *you never struggle*. The fix is mechanical: **every tutorial you watch must produce a project you built without the video.** For every hour of content, spend three hours building something. Start absurdly small — a script that scrapes a webpage, a form that saves to a database — and let the building pull you forward. Finished code you wrote yourself is the only thing that transfers to interviews. Close the tab, open your editor.
