# Build Your Git & GitHub Portfolio

## Objective
Your GitHub is your open portfolio. A clean contribution graph, a polished profile, and a few well-documented repos signal "engineer" before an interviewer ever reads your resume.

## Steps
1. **Learn Git properly** — branches, merges, rebase, resolving conflicts. Practice via [GitHub Skills](https://skills.github.com/) or the [git-github roadmap](https://roadmap.sh/git-github).
2. **Create a professional profile:** clear bio, pinned repos, a profile README with your skills and focus area.
3. **Make it a habit to commit daily** — even small commits. A green graph proves consistency, which recruiters do check.
4. **Open-source a few repos:** your projects with good READMEs, screenshots, and license files.
5. **Start contributing** — find `good first issue` labels on repos (see the open-source opportunity card). Even one merged PR a semester is excellent.

## Proof
- A 30+ day commit streak.
- GitHub profile with bio, pinned repos, and a profile README.
- At least 1 merged open-source PR.

## Mentor Note
Your GitHub is your technical resume — treat it like one. A neat profile with pinned projects and a real commit history beats a flashy certificate collection. Interviewers will open your repos, so keep the code clean and documented.
