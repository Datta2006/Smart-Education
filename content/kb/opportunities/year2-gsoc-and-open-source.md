# Open Source Programs (GSoC, Outreachy, Hacktoberfest)

## Objective
Open-source programs give you **real-world engineering experience, mentorship, and a resume line** that interviewers instantly respect — without needing a job application. Year 2 is the perfect time to start contributing.

## Opportunities
1. **Google Summer of Code (GSoC)** — The most prestigious program. Work 12+ weeks with a mentor on a real open-source project for a stipend ($750–$3,000 USD). **Eligibility:** 18+, any student — no prior experience required. Timeline (2026): applications open ~March 16–31, accepted projects announced April 30, coding May–August. Start contributing to candidate orgs months before applying. → https://summerofcode.withgoogle.com/
2. **Outreachy** — Paid 3-month remote internship for people from under-represented groups in tech, with an emphasis on mentorship. Twice a year (May and December cohorts). → https://www.outreachy.org/
3. **Hacktoberfest** — Annual October challenge: submit 4 PRs to any GitHub repo, get swag + practice. Low barrier, great for your first merged PRs. → https://hacktoberfest.com/
4. **MLH Fellowship** — 12-week remote program pairing students with open-source projects and mentors. → https://fellowship.mlh.io/
5. **GitHub Student Developer Pack** — Free developer tools (JetBrains, DigitalOcean credits, etc.) while you're a student. Claim it now. → https://education.github.com/pack

## Action Steps
- This month: create a GitHub profile, find 2–3 active projects with `good first issue` labels, and make your first PR.
- Set calendar reminders for GSoC/Outreachy application windows (they're seasonal).
- Contribute consistently: even 1 PR a month builds the track record that gets you into these programs.

## Mentor note
These programs are *mentorship in disguise* — you get senior developers reviewing your code for free. And a GSoC or Outreachy line on your resume opens doors that cold applications can't. Rejection is normal (GSoC is competitive); the contribution history you build while trying is itself the reward.
