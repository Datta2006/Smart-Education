# Master One Core Syntax Base

## Objective
Write a program from scratch using loops, conditionals, arrays, and functions without looking at a tutorial.

## Steps
1. Pick one language: C++, Java, or Python. (C++ or Java preferred for future DSA).
2. Install a local IDE like VS Code and set up the compiler.
3. Solve 5 basic pattern printing problems (e.g., pyramid stars).
4. Solve 10 basic array manipulation problems (e.g., reverse an array, find the second largest number).
5. Solve 10 basic string problems (e.g., check for palindrome, count vowels).

## Proof
- A GitHub repository containing these 25+ solved problems.
- A commit history showing consistent effort over a few weeks, not a single bulk upload.

## Estimated time
40 hours (approx. 4 hours a week for a month).

## Mentor note
Syntax is just vocabulary. Logic is the language. Do not memorize the code. Understand how the array index moves.
