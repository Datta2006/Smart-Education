# Stuck on a DSA Problem

## Trigger condition
The student has spent 30+ minutes on a single problem and is frustrated or considering giving up on DSA.

## Mentor message
Being stuck is the actual training. If you solved every problem instantly, you'd learn nothing — interviews exist precisely to find what you *can't* do yet. Follow the 20-minute rule: struggle for 20 minutes (draw examples, try brute force, name the pattern), then read the solution and *learn it* — write the pattern and complexity in your problem log. Stuck-ness is not a signal about your ability; it's a signal about your current pattern vocabulary. Every expert once stared at Two Sum. The only real failure is peeking at the solution in the first five minutes, because that skips the struggle that builds the recognition muscle. Tomorrow, revisit the same problem cold. That revisit is where the learning lands.
